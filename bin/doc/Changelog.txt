Birdman Changelog
=================

1.1 (2026-09-14)
- Increased window and game area to 960x720 (1.5x original 640x480)
- Bird sprites scaled to 128x128 pixels (2x, using 4-point GpiBitBlt stretch)
- Fixed: New Game (Ctrl+N) now clears screen before starting fresh
- Open Watcom 2.0 build system (makefile.wat, compile-wat.cmd)
- Standard menu layout: Game / Options / Help
- Keyboard shortcuts: Ctrl+N New Game, Ctrl+P Pause, Ctrl+Q Quit, Ctrl+X Exit
- Language support: English, Spanish, Dutch, German, French, Italian
- Settings persistence (BIRDMAN.CFG): language, save-on-exit flag
- Background Run option: pause game on focus loss (Ctrl+B)
- Frame Controls toggle: hide/show title bar and menu bar (Ctrl+F)
- About dialog: standard OS2World format
- BLDLEVEL string embedded in executable
- Division-by-zero guard in score display
- .def file: updated to WINDOWAPI, STACKSIZE 65536, HEAPSIZE 4096
- DLL screen saver code moved to legacy/ (EXE-only build retained)
- Bird click and double right-click suppressed when game is paused
- WinReleasePS replaces GpiDestroyPS for WinGetPS-obtained handle

0.01 (1998-08-19)  Mike, Vienna
- Initial release as OS/2 screen saver module and standalone EXE
- Birds fly right to left, animated sprite sheet (5 frames)
- Left click to shoot, double right-click to kill all
- Score shown in title bar: killed / survived / percentage
